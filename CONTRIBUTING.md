# Contributing

Contributions are welcome and greatly appreciated.

If you would like to improve this project, please follow these guidelines:

## Reporting Issues

Please use the GitHub **Issues** page to report:

- Bugs
- Build problems
- Documentation errors
- Feature requests
- Suggestions for improvement

When reporting an issue, include:

- STM32CubeIDE version
- Target board and MCU
- Steps to reproduce the problem
- Error messages or build logs (if applicable)

## Pull Requests

Before submitting a pull request:

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused on a single topic.
4. Test the project before submitting.
5. Update documentation if necessary.

## Coding Style

Please follow the existing project style:

- Use consistent formatting.
- Prefer descriptive names.
- Keep functions short and readable.
- Document non-obvious code.
- Avoid unnecessary dependencies.

## Commit Messages

Use clear and concise commit messages.

Examples:

```text
Fix USART initialization
Add SPI example
Update README
Refactor GPIO configuration
```

## Testing

Before submitting changes, verify that:

- The project builds successfully in both **Debug** and **Release** configurations.
- No compiler warnings are introduced.
- Existing functionality continues to work as expected.

## Questions

If you have questions or suggestions, feel free to open a GitHub Issue.

Thank you for helping improve this project!
